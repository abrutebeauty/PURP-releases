# PURP releases

Ready-to-run Mac builds of PURP, Eman's vocal-recording app. The app's code lives in a private repo; this public repo only holds the builds.

- **First time:** download `PURP-mac.zip` from the [latest release](https://github.com/abrutebeauty/PURP-releases/releases/latest), unzip it, drag PURP into Applications, then right-click PURP and choose Open (needed once, because the app isn't signed with an Apple certificate yet).
- **After that:** PURP checks here by itself and shows "Restart to update" when a new build is ready. No more downloading.

Each release is tagged `build-<number>` and is published automatically by the Mac build in the PURP code repo.
